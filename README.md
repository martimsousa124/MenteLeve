# Mente Leve — demonstração escolar

Site estático para abrir diretamente no browser. Não precisa de Python, terminal,
servidor local, instalação ou conta num serviço externo.

## Apresentar

1. Abre `index.html` com duplo clique.
2. Usa **Criar conta** para criar a única conta de utilizador neste browser.
3. O diário e os pedidos ficam guardados no armazenamento local do browser.
4. A área de administração está no link no fundo da página.

Credenciais de demonstração da administração:

- Email: `admin@gmail.com`
- Palavra-passe: `admin123`

O botão **Reiniciar demonstração e apagar dados** na página de administração
apaga a conta de utilizador, o diário e todos os pedidos guardados neste browser.

## Limites importantes

- É uma simulação de apresentação, não um serviço real. Os pedidos de consulta,
  contactos e mensagens não são enviados a ninguém.
- Os dados ficam no browser e neste dispositivo; não são sincronizados para
  outros computadores.
- A autenticação local não é segura: a conta de admin e os dados podem ser
  inspecionados ou alterados por alguém com acesso ao browser ou aos ficheiros.
- Usa dados fictícios. Não guardes informação pessoal, palavras-passe usadas
  noutros serviços ou informação de saúde real.
- A Mente Leve não presta cuidados de saúde nem é um serviço de emergência.

Para apagar todos os dados, usa o botão de reinício da demonstração ou limpa os
dados locais do browser.
